## APIs

- **Fashion Diffusion Public API** — REST API for AI fashion tasks. Bearer API key authentication (Authorization: Bearer fd_live_xxx). Currently documented endpoints cover Virtual Try-On: submit task (POST /virtual-try-on/tasks, returns 202), query task (GET /tasks/{taskId}), and list tasks (GET /tasks). JSON request bodies with image URLs or Base64 data URLs. (`https://www.fashiondiffusion.ai/api/public/v1/`)
